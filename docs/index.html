Technical Architecture & Key Innovations

🎯

AVX2 Vectorized Popcount

Uses parallel 256-bit SIMD nibble shuffle lookup tables (PSHUFB + VPSADBW) specifically engineered for AMD Zen 2 and Intel Skylake CPUs lacking AVX-512 vpopcntd instructions.

💾

Ultralight Footprint

Compiled shared library is just 15.65 KB (319x smaller than official C++ bindings) and uses 18.5% less RAM RSS during continuous execution.

⚡

Zero Python Allocation Overhead

Passes 32-byte SIMD memory aligned pointers directly via ctypes, eliminating object wrappers, heap allocation loops, and C++/Python conversion overhead.

Quick Start Guide

1. Building Assembly Core

# Install build prerequisites (NASM & GCC)
sudo apt install nasm gcc make

# Compile assembly into libspcore.so
cd src && make

2. Python Usage Example

import numpy as np
from bindings.sp_wrapper import SpatialPoolerNASM

# Initialize 2048-bit Input, 1024-column Spatial Pooler
sp = SpatialPoolerNASM(input_dimensions=2048, column_dimensions=1024)

# Create 5% active bit input SDR
input_sdr = (np.random.rand(2048) < 0.05).astype(np.uint8)

# Compute overlaps using AVX2 NASM core (returns uint32 NumPy array)
overlaps = sp.compute(input_sdr)
print("Overlap Counts per Column:", overlaps[:10])
